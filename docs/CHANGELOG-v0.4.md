# v0.4.0 — виправлення за звіркою з florentbr/OWON-VDS1022

1. **Апаратне вирівнювання за `cursor`.** Поле u16 на +9 у DM-заголовку — це позиція
   тригера в кадрі (від правого краю). Тепер вікно відображення будується від неї:
   тригер стоїть на 1/4 ширини, як і раніше, але без програмної евристики.
   Програмний пошук фронту лишився запасним варіантом, якщо `cursor` = 0.
2. **Апаратний частотомір.** Частота береться з приладу: `f = period_num / time_sum × 100 МГц`.
   Для роботи частотоміра додано запис `SET_FREQREF` (0x4A/0x4B) = рівень тригера − 5.
   Підрахунок фронтів лишився запасним (у статусі позначка `h` або `s`).
3. **Auto-режим без опитування статусу.** Прибрано два зайвих round-trip на кадр
   (TRG_D і datafinished): у Auto вони не потрібні, прилад сам відповідає `'E'` (EBUSY),
   поки дані не готові. Для «Однократно» опитування увімкнене.
4. **Тригер по спаду і по будь-якому каналу.** Слово тригера (рег 36) тепер пишеться явно:
   біти 13 (канал), 12 (фронт), 10-11 (sweep). Рівень тригера пишеться парою
   `[верхній, нижній]` з гістерезисом 10 кодів і зсувом +10 для спаду.
   У UI додано спінер «CH1 ↑ / CH1 ↓ / CH2 ↑ / CH2 ↓».
5. **Peak detect.** Галочка «Peak» вмикає режим пікового детектування (`SAMPLE` = 1) —
   на повільних розгортках видно викиди, які інакше зникають через децимування.
6. **PRE/SUF_TRG за формулою офіційного ПЗ** з поправкою `HTP_ERR = 11` (2539 / 2561).
7. **Знято обмеження малювання ±100 кодів.** Сигнал, більший за 4 поділки від нуля,
   більше не малюється пласкою лінією по краю екрана.


## v0.4.2 (виправлення за hex-дампами заголовка)

* Заголовок кадру читається з байтів 0..10 пакета, а не з +111 (де вже семпли).
* Підтверджено на залізі (VDS1022I, FPGA V2): `cursor` = 5108 (сталий) і `period_num` = 0 —
  апаратні позиція тригера й частотомір цієї FPGA непридатні.
* Повернули програмне вирівнювання за фронтом і програмний підрахунок частоти.
  Апаратну частоту приймаємо лише якщо вона ненульова і збігається з програмною (0.5x..2x).
* Лишилися з v0.4.0: тригер по спаду/каналу, Peak, PRE/SUF з HTP_ERR, Auto без опитування,
  автопідстройка рівня, зняте клампування.
